# Communication protocols and research

Reviewed November 23, 2026. This review checks primary documentation and publication records, and inspects public artifacts where accessible. A code release does not establish that a result has been independently reproduced. Numbers below are authors' measurements with their original comparators. For SG-001, no implementations or model experiments were run.

## Agent interoperability and existing components

| Source and status | Relevant primitives | Reuse and limits |
| --- | --- | --- |
| [MCP, July 28, 2026 specification](https://modelcontextprotocol.io/specification/2026-07-28) | Host/client/server roles for tools, resources, and prompts, versioned operations, authorization guidance, and extensions. The [release notes](https://blog.modelcontextprotocol.io/posts/2026-07-28/) describe stateless core changes. | Use for tool calls and evidence access. A tool can report structured results. That does not supply a shared vocabulary for peer claims or review verdicts. [Official Python SDK](https://github.com/modelcontextprotocol/python-sdk), MIT. |
| [A2A, v1.0.0, March 2026](https://a2a-protocol.org/v1.0.0/specification/) | Agent Cards, skills, supported interfaces and extensions, task status, message/context IDs, text and data Parts, Artifacts, and authentication and authorization flows. In-task authorization signals a need for credentials. Scope and validity are evaluated by the external authorization mechanism. | Use as the direct control and candidate carrier. Existing domain-specific structured artifacts may suffice. An extension should focus on any demonstrated loss of semantics, including the difference between task completion and the result of a check. [Specification source](https://github.com/a2aproject/A2A) and [official Python SDK](https://github.com/a2aproject/a2a-python), Apache-2.0. The project also published a [v1.0.1 patch release](https://github.com/a2aproject/A2A/releases/tag/v1.0.1). |
| [IBM/BeeAI ACP](https://github.com/i-am-bee/acp), launched March 2025 | REST runs, manifests, sessions, multipart messages and citation metadata. Public code includes SDKs and examples under Apache-2.0. | Relevant precedent for source attribution and task handoffs. [The project announced convergence with A2A in August 2025](https://github.com/orgs/i-am-bee/discussions/5). Treat archived contracts and migration as historical study. Convergence does not imply wire compatibility. Here ACP means Agent Communication Protocol, not other projects using the same acronym. |
| [ANP, specification set 1.2](https://github.com/agent-network-protocol/AgentNetworkProtocol) | DID-based identity and authentication, agent description/discovery and messaging profiles. ANP-05 authorization and ANP-06 semantic negotiation are drafts. | Relevant when identities span organizations and for evaluating negotiation overlap. SG-002 can provision local peers with less setup. Review specific SDK/profile support before making compatibility claims. The root project is Apache-2.0 with separate notices for some materials. |
| [FIPA ACL Message Structure](https://ppgia.pucpr.br/~fabricio/ftp/Aulas/Mestrado/AS/Aula3/SC00061G_FIPA_ACL.pdf), December 2002 specification, FIPA rights notice | Communicative acts, sender/receiver, content language, ontology and conversation correlation. | Reuse the distinction between intent, content and conversation metadata. Shared communicative acts already have a precedent. The experiment only needs application-level distinctions that carry through modern carriers and models. |
| [CloudEvents v1.0.2](https://cloudevents.io/), February 2022 release | Event identifiers, source and type, data content type and schema reference, with multiple bindings. Apache-2.0 project with SDKs. | Reuse if a carrier requires event routing. Event context supplies no universal decision vocabulary. Avoid wrapping A2A messages in a second mandatory envelope. |
| [JSON Schema 2020-12](https://json-schema.org/draft/2020-12), published draft family | Validates structure and field constraints, with reusable definitions and references. [Python jsonschema](https://github.com/python-jsonschema/jsonschema), MIT. | Pin a schema and references locally for the structured arms. A shape validator cannot verify claims or authorize actions. Give failure semantics explicit application rules. |
| [W3C PROV-O](https://www.w3.org/TR/prov-o/), April 2013 Recommendation | Entities, activities, agents and relations for derivation, attribution and generation. Document rights are stated by W3C. | Reuse compatible provenance concepts. A mapping to richer provenance graphs can follow a demonstrated need. Provenance provides traceability. A trace still needs evidence and a trust decision. |
| [CBOR, RFC 8949](https://www.rfc-editor.org/rfc/rfc8949.html), December 2020 Standards Track, and [Protocol Buffers](https://github.com/protocolbuffers/protobuf) | CBOR provides compact binary serialization. Protocol Buffers provides schema-defined messages and generated codecs. RFC text carries IETF Trust terms. [cbor2](https://github.com/agronholm/cbor2) is MIT and the Protobuf runtime repository is BSD-3-Clause. | Compare wire bytes, encode/decode and schema evolution separately from model input. Rendering decoded data as the same text gives the model the same tokens. No general speed or token claim follows from the formats. |

ADOL is the **Agentic Data Optimization Layer**, an [individual Internet-Draft, revision 02](https://datatracker.ietf.org/doc/draft-chang-agent-token-efficient/), dated January 12, 2026 and listed as expired. It proposes reusable JSON references, conditional field inclusion, output-verbosity controls, and selective retrieval across data layers such as MCP and A2A. The [draft text](https://www.ietf.org/archive/id/draft-chang-agent-token-efficient-02.html) is under IETF Trust terms. Its examples motivate a short-key and selective-retrieval control. Removing optional data can hide evidence or context needed for a later decision. A reference implementation or reproducible measured speedup was not verified from the draft.

## Structured, symbolic, and emergent communication

| Work and publication | Evidence and limitation | Implementation and reuse |
| --- | --- | --- |
| Chen et al., [AutoForm](https://aclanthology.org/2024.findings-emnlp.623/), EMNLP Findings, November 2024 | Models choose alternate formats for reasoning and communication. The authors report up to 72.7% lower token use in their multi-agent communication tasks and demonstrate reuse of formats across tested models. This is a task-specific maximum and documents format choice, not a portable semantics contract. | [Code](https://github.com/thunlp/AutoForm), Apache-2.0. Reuse its comparison idea for prose, JSON, and compact notation. |
| Mou et al., [EcoLANG](https://aclanthology.org/2025.findings-emnlp.284/), EMNLP Findings, November 2025 | Induces compact language rules on a corpus. Reports over 20% lower token consumption while preserving simulation accuracy in reported social simulation experiments, using Llama-3.1-8B-Instruct and PHEME/HiSim. This domain does not test independent engineering handoffs. | [Code](https://github.com/xymou/EcoLANG), MIT. Count both induction and the model-visible rules when adapting its comparison. |
| Marro et al., [Agora](https://arxiv.org/abs/2410.11905), October 14, 2024 preprint | Reuses standard routines for common exchanges, natural language for rare exchanges, and model-written routines in between. The [paper's configured 100-agent demo](https://arxiv.org/html/2410.11905v1#S5.SS3) reports $7.67 versus $36.23 in hosted model costs over 1,000 synthetic service requests. Repeated executable routines avoided model calls in that workload. The demo leaves independent receiver fidelity, authority enforcement, and offline performance open. | [Paper demo](https://github.com/agora-protocol/paper-demo) uses hosted services and lists setup steps, with no separately verified license. The [core Python package](https://github.com/agora-protocol/python) is MIT and the manuscript is CC BY 4.0. Reuse the fallback and amortization ideas when evaluating negotiated vocabularies. |
| Pei, Huang and Wang, [CLSR](https://proceedings.mlr.press/v306/pei26a.html), ICML, July 2026 | Agents generate and evolve compact rule sets. A router selects or composes them at test time. The authors report 3–6× fewer latency-oriented completion tokens on their reasoning comparisons with standard chain-of-thought at similar accuracy. This counts generated tokens against verbose reasoning, not total prompt tokens, time, mixed-model compatibility or performance against a concise handoff. | The [June 2026 preprint](https://www.alphaxiv.org/abs/2606.29354) points to the project at `github.com/pzqpzq/LSF_MDia`. A cached repository listing includes configs, examples and a license file. Live retrieval returned not found, and license terms could not be confirmed. Inspect before reuse and include routing, evolution and glossary cost. |
| Mordatch and Abbeel, [Emergence of Grounded Compositional Language](https://ojs.aaai.org/index.php/AAAI/article/view/11492), AAAI, April 2018 | Cooperative agents learn discrete signals in a grounded simulation. The work demonstrates emergence under task and training constraints. It supplies no result on arbitrary independent LLMs, latency, or interoperability. | Paper available. No author runnable implementation or code license verified here. Reuse the conceptual distinction between task utility and portable meaning. |
| Kottur et al., [Natural Language Does Not Emerge Naturally in Multi-Agent Dialog](https://aclanthology.org/D17-1321/), EMNLP, September 2017 | In a two-agent reference game, near-perfect task reward can coexist with poorly interpretable, non-compositional signals. The controlled setting is much narrower than orchestration. | Paper available through ACL Anthology. No runnable artifact or code license verified here. Use held-out peers and independent audits to test whether negotiated rules transfer. |

## Latent and hybrid communication

| Work and publication | Reported conditions and results | Implementation, limitations and relevance |
| --- | --- | --- |
| Du et al., [Interlat](https://aclanthology.org/2026.acl-long.1248/), ACL, 2026. [First preprint](https://arxiv.org/abs/2511.09149), November 12, 2025 | Learned alignment sends hidden-state sequences. The [author's results summary](https://xiaodu-flying.github.io/posts/interlat/) reports 65.42% unseen ALFWorld success versus 62.44% for text communication on Qwen2.5-7B. Qwen latents passed to a Llama actor through an adapter reached 71.39% unseen success. On MATH, full CoT scored 38.35% overall versus Interlat's 36.88%. | [Official code](https://github.com/XiaoDu-flying/Interlat), Apache-2.0, with training and evaluation instructions. Hidden-state and adapter access matter. Compressed message-generation time is a component measurement. The study establishes feasibility for specific model/adapter pairs. |
| Zou et al., [LatentMAS](https://proceedings.mlr.press/v306/zou26k.html), ICML, July 2026. [Preprint](https://arxiv.org/abs/2511.20639), November 2025 | Training-free latent collaboration with internal model access. Across nine reasoning and code benchmarks, authors report 70.8–83.7% fewer output tokens and 4–4.3× end-to-end inference speedup in reported comparisons. | [Code and data repository](https://github.com/Gen-Verse/LatentMAS), Apache-2.0 code. Candidate reference for a compatible-pair ablation. KV or hidden-state transfer requires compatible implementations and access. Treat these numbers as implementation and workload dependent. |
| Mou et al., [HyLaT](https://aclanthology.org/2026.emnlp-main.181/), EMNLP, October 2026. [Preprint](https://arxiv.org/abs/2605.25421), May 25, 2026 | Two-stage trained latent/text dialogue. Three agents, two turns, first 300 questions per dataset, eight QA datasets. Table 2 averages versus the matched trained text arm are 58.08% vs 59.41% majority accuracy, 72.01 vs 505.03 generated tokens, and 1.47 vs 5.47 seconds per question. The trained latent baseline averages 56.29%, 57.00 tokens and 0.70 seconds. | [Official training and evaluation code](https://github.com/xymou/hylat), Apache-2.0. Model-visible text can convey important conclusions while latent content carries extra detail. This setup relies on trained peers, and token counts do not price latent prefill, training, or audit work. |
| Zhang et al., [LatCom](https://aclanthology.org/2026.emnlp-main.1068/), EMNLP, October 2026. Preprint arXiv:2609.37017, September 29, 2026 | Two-stage training compresses multiple senders into fixed slots for a frozen receiver. Experiments with Qwen3-4B report mean 2.46× faster inference and 70.3% fewer output tokens relative to LatentMAS with comparable mean accuracy on the authors' seven benchmarks. | [Paper and appendix](https://aclanthology.org/2026.emnlp-main.1068.pdf) describe training and ablations. A public author implementation and code license were not verified. Fixed receiver-readable slots trade away reconstruction, and homogeneous results do not establish heterogeneity, preservation of rare evidence, or a compute win at TAM scale. |
| Yang et al., [XBridge v2](https://arxiv.org/abs/2608.11676v2), September 28, 2026 revision, with NeurIPS 2026 acceptance reported by authors | Transfers lexical anchors and model-state enrichment through a learned bridge. Tests Llama, Qwen and Mistral directions on seven benchmarks and reports 11× lower latency compared with its text baseline. A bridge-only ablation shows trouble retaining entity identity. | Archive lists manuscript license and source. A runnable author release and code license were not verified. A trained bridge and exact endpoints are material prerequisites. Cross-family compatibility for selected checkpoints is evidence to measure, not a universal interchange guarantee. |

## Overhead and experimental reuse

- [ProtocolBench](https://proceedings.mlr.press/v306/du26l.html), ICML 2026, first [posted October 2025](https://arxiv.org/abs/2510.17149), compares success, latency, message/byte overhead and resilience. Its Streaming Queue scenario reports a 36.5% spread in completion time and 3.48 s difference in mean end-to-end latency. Its [MIT-licensed benchmark](https://github.com/ulab-uiuc/AgentProtocols) is a starting point for failure injection and lifecycle instrumentation. Protocol/binding implementation effects and workload details matter. The results do not rank semantic formats.
- [The Cost of Saying Hello](https://github.com/pvarshh/handshake-benchmark) is a 2026 preprint with a related non-archival workshop poster acceptance reported by the author. The MIT-licensed package lists official Python SDKs, 50 runs per cell, loopback or emulated links, per-phase timings, bytes and raw logs. On the paper's emulated 50 ms RTT condition the preprint (arXiv:2610.30151, linked from the reproducibility package) reports 230 ms for legacy MCP and 61 ms for A2A. Modern MCP and warm connections alter those results. This is handshake overhead, with additional model-visible metadata cost when capability descriptions enter context. Reuse the phase boundaries and report cold/warm costs separately.
- [A survey of agent interoperability protocols](https://arxiv.org/abs/2505.02279), May 2025 preprint, provides an early taxonomy of MCP, ACP, A2A and ANP. Its protocol snapshots predate several releases and the ACP convergence. It supplies qualitative context without a controlled speed comparison. No executable comparison or implementation license was verified.

Start experiments with a pinned A2A SDK, a local schema validator, synthetic artifacts, and a direct A2A configuration that can use its full native data model. Use MCP for tool and resource access only where the prototype needs that boundary. Reuse measurement ideas from ProtocolBench and the handshake harness without equating their latency measures with generated output tokens, message generation, or inference time in the latent papers. Verify artifact, model and dataset license terms independently before running a replication.

The evidence supports testing shared semantic conventions and different encodings independently. It leaves open whether any of them improves complete multi-model tasks with evidence, authorization and audit requirements. The [benchmark plan](../benchmarks/BENCHMARK_PLAN.md) targets that gap.
